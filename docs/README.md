## Arbeitsregel

Bei jedem größeren Schritt werden drei Dinge gemeinsam aktualisiert:

1. Code
2. passende Detaildokumentation
3. `ROADMAP_STATUS.md`

So soll verhindert werden, dass Dokumentation und tatsächlicher Repo-Stand wieder auseinanderlaufen.
